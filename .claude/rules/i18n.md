# Localisation rules
- UA is the source language; RU must have the same key set (a unit test enforces parity).
- Keys: `area.thing.variant`. No sentence building by concatenation — use placeholders.
- Wording must match `docs/GLOSSARY.md`; a new term goes into the glossary in the same PR.
- Tone: absurd office humour. No profanity, no real brands, no real people.
- Bot chat phrases are templates filled from match events; no AI service calls.
