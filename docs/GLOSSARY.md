# Глосарій

Перед тим як назвати щось нове, шукайте тут. Позначка «(план)» у колонці «У коді» означає, що цього в коді ще немає.

| Термін | Значення | У коді |
|---|---|---|
| Партія | одна гра від лобі до екрана перемоги | `WorldState`, `src/sim/world.ts` |
| Сід | число, з якого будується офіс; однаковий сід дає однаковий офіс | `Level.seed`, параметр `?seed=` у посиланні |
| Курча | чесний учасник: виконує завдання й шукає Гуся | `role: 'chick'` (план) |
| Гусь-Диверсант, Гусь | замаскований шкідник, один на партію | `role: 'goose'` (план) |
| Бот | учасник, яким керує гра | `isBot` (план) |
| Ознака Гуся | видовжена шия та бульбашка «га-га?», які видають Гуся зблизька | `gooseTell` (план) |
| Клітинка | квадрат поверху 1×1 м: підлога, стіна або вікно | `Level.cells`: `FLOOR`, `SOLID`, `GLASS` |
| Сектор | одна з дев'яти частин поверху, у якій стоїть одна кімната | `SECTORS`, `placeRooms` |
| Хаб | незмінна частина кімнати: її впізнавані меблі й робочі місця | `PREFABS`, `Prop.hub`, `CORE` |
| Наповнення | меблі й рослини, які гра розставляє щоразу по-новому | `FILLERS`, `furnish` |
| Масив | товстий непрохідний шматок стін між кімнатами | клітинки `SOLID` |
| Закуток | тупикова кишеня коридору | `NOOKS`, `carveCorridors` |
| Фасад | край поверху з панорамними вікнами | клітинки `GLASS`, `glaze` |
| Огляд | те, що курча бачить по прямій | `computeVisibility`, `WorldState.visible` |
| Туман огляду | сіре й бляклe зображення всього поза оглядом | `withFog`, `fogUniforms` |
| Зріз стіни | стіна перед курчам, опущена до бордюру | `CUTAWAY_REACH`, `WALL_LOW` |
| Емоція | вираз обличчя курчати за ситуацією | `Emotion`, `PlayerState.emotion` |
| Зелена зона | кімната без завдань: оранжерея або кавопоінт | `RoomType`: `'lounge'`, `'greenhouse'` |
| Завдання, таска | робота курчати; заповнює спільну шкалу | `Task`, `src/sim/tasks.ts` |
| Робоче місце | меблі хабу, біля яких клавішею `E` відкривається завдання | `Station`, `STATION_PROPS` |
| Спільна шкала, спільний прогрес | частка виконаних завдань усіх учасників | `taskProgress`, `#progress` |
| Стрілка завдання | жовта стрілка над робочим місцем із незробленим завданням | `src/render/markers.ts` |
| Мініігра | вікно, у якому виконується завдання; `Esc` закриває без прогресу | `src/minigames/`, `createMinigameHost` |
| Візуальне завдання | завдання, ефект якого бачать інші в кімнаті; доводить, що виконавець не Гусь | `Task.visual` (план) |
| Коробка-вантаж | коробка із завдання «Вантажник»; стукає й іноді падає | `Box.kind: 'cargo'`, `src/sim/cargo.ts` |
| Підказка доставки | нечіткий опис кімнати, куди нести коробку | `cargo.hint.*`, `Task.target` |
| Вислизнути | коробка падає з крил на маршруті | `BOX_SLIP_CHANCE`, `rollSlip`, подія `boxSlipped` |
| Коробка «ГАРЯЧА ВІДПУСТКА» | коробка із запакованим курчам; зблизька дає репорт | `Box.kind: 'vacation'` (план) |
| Запакувати | дія Гуся, що виводить курча з гри | `PackCommand` (план) |
| Репорт | повідомлення про знайдену коробку з колегою, клавіша `R`; скликає збори | `ReportCommand` (план) |
| ТЕРМІНОВИЙ СОЗВОН, збори | обговорення й голосування в Мітинг-Румі | `Meeting` (план) |
| Саботаж | шкода від Гуся, яку курчата мають полагодити | `Sabotage` (план) |
| Перегрів рендер-ферми | саботаж: гасне світло, звужується поле зору | `Sabotage.Overheat` (план) |
| Терміновий дзвінок Модуса | саботаж із таймером 45 секунд і двома підписами NDA | `Sabotage.ModusCall` (план) |
| Модус | баєр, який сипле токсичними правками | `i18n: minigame.modus.*` |
| Замовник | автор абсурдного брифу в «Семи червоних перпендикулярних лініях» | `minigame.lines.client`, `paintClient` |
| Бриф | набір суперечливих вимог Замовника; щоразу новий | `Brief`, `createBrief`, `src/minigames/lines` |
| Чорнило | справжній колір лінії: червоне, зелене, синє, прозоре | `Ink` |
| ТЕГ, колір за документами | штамп, що оголошує лінію потрібного кольору | `Line.tag`, `TagColor`, `declared` |
| Штамп 90° | «Замовник вірить»: лінія перпендикулярна всім | `Line.forced` |
| Кошеня | лінія, перетворена на контур котика; лишається лінією | `Line.kitten` |
| Планшет «Брифінг із Замовником» | робоче місце мініігри з лініями в Мітинг-Румі | проп `briefTablet` |
| Правка | стікер-зауваження Модуса в мініігрі | `src/minigames/modus`, `Sticker` |
| Хаос | шкала мініігри «Відбитись від правок Модуса»; на 100% раунд з початку | `ModusState.chaos` |
| Креос конкурентів, плата | ліва (зразок) і права (ваша) схеми в «Креатив один в один» | `src/minigames/copycat` |
| Креос, креатив | рекламний ролик або банер, який робить офіс | — |
| Новостнік | креатив у стилі випуску новин | `minigames/news` (план) |
| Стак | спільний буфер файлів у «Монтажі новостніків» | `NewsState.stack`, `src/minigames/news` |
| Нода | вузол, у який напарник вкидає файл зі Стаку | `NewsState.litNode` |
| Напарник-бот | бот, що сідає в «Монтаж новостніків», якщо ніхто не прийшов | `NewsState.botPartner`, `NEWS_PARTNER_DELAY` |
| Екстрені Новини | ролик на екрані в Лобі після «Монтажу новостніків» | `WorldState.broadcast`, `src/render/broadcast.ts` |
| Підказка дії | напис унизу: що зробить `E` зараз | `Prompt`, `#prompt` |
| Велетенська Зелена Кнопка | кнопка, що запускає Екстрені Новини | проп `dualStation` |
| Баєр | спеціаліст із закупівлі реклами; частина лору | — |
| Капа | денна норма замовлень у рекламній кампанії; частина лору | — |
| Проп | предмет інтер'єру: стіл, стійка, рослина | `Prop`, `src/render/props.ts` |
| Новий офіс | кнопка, що будує офіс із нового сіду | `startOffice`, `src/main.ts` |
