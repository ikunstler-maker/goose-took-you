# Глосарій

Перед тим як назвати щось нове, шукайте тут. Колонка «У коді» до завершення етапу 1 — план.

| Термін | Значення | У коді |
|---|---|---|
| Партія | одна гра від лобі до екрана перемоги | `Match` |
| Сід | число, з якого будується офіс; однаковий сід дає однаковий офіс | `seed` |
| Курча | чесний учасник: виконує завдання й шукає Гуся | `role: 'chick'` |
| Гусь-Диверсант, Гусь | замаскований шкідник, один на партію | `role: 'goose'` |
| Бот | учасник, яким керує гра | `isBot` |
| Ознака Гуся | видовжена шия та бульбашка «га-га?», які видають Гуся зблизька | `gooseTell` |
| Слот | клітинка сітки поверху, куди ставиться кімната | `Slot` |
| Кімната-префаб | кімната з незмінним інтер'єром, яку гра розставляє по слотах | `RoomPrefab` |
| Хаб | незмінний інтер'єр кімнати: меблі й робочі місця | `RoomPrefab.props` |
| Зелена зона | слот без завдань: оранжерея або кавопоінт | `RoomType.Lounge` |
| Завдання, таска | робота курчати; заповнює спільну шкалу | `Task` |
| Мініігра | екран, на якому виконується завдання | `src/minigames/` |
| Візуальне завдання | завдання, ефект якого бачать інші в кімнаті; доводить, що виконавець не Гусь | `Task.visual` |
| Коробка-вантаж | коробка із завдання «Вантажник»; стукає й іноді падає | `Box.kind: 'cargo'` |
| Коробка «ГАРЯЧА ВІДПУСТКА» | коробка із запакованим курчам; зблизька дає репорт | `Box.kind: 'vacation'` |
| Запакувати | дія Гуся, що виводить курча з гри | `PackCommand` |
| Репорт | повідомлення про знайдену коробку з колегою, клавіша `R`; скликає збори | `ReportCommand` |
| ТЕРМІНОВИЙ СОЗВОН, збори | обговорення й голосування в Мітинг-Румі | `Meeting` |
| Саботаж | шкода від Гуся, яку курчата мають полагодити | `Sabotage` |
| Перегрів рендер-ферми | саботаж: гасне світло, звужується поле зору | `Sabotage.Overheat` |
| Терміновий дзвінок Модуса | саботаж із таймером 45 секунд і двома підписами NDA | `Sabotage.ModusCall` |
| Модус | баєр, який сипле токсичними правками | `i18n: modus.*` |
| Правка | стікер-зауваження Модуса в мініігрі | `minigames/modus` |
| Креос, креатив | рекламний ролик або банер, який робить офіс | — |
| Новостнік | креатив у стилі випуску новин | `minigames/news` |
| Стак | спільний буфер файлів у «Монтажі новостніків» | `AssetStack` |
| Екстрені Новини | ролик на екрані в Лобі після «Монтажу новостніків» | `LobbyBroadcast` |
| Велетенська Зелена Кнопка | кнопка, що запускає Екстрені Новини | `GreenButton` |
| Баєр | спеціаліст із закупівлі реклами; частина лору | — |
| Капа | денна норма замовлень у рекламній кампанії; частина лору | — |
