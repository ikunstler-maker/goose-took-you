# Гусь тебе побрав

Браузерна ізометрична 3D-гра на соціальну дедукцію: чібі-курчата проти замаскованого Гуся в сонячному офісі.

- Специфікація та етапи: `docs/SPEC.md`
- Рішення: `docs/decisions.md`
- Як працювати з Claude: `docs/MASTER_GUIDE.md`, частина B

Запуск для розробки: `npm install`, потім `npm run dev`. Перевірка перед PR: `npm run check`.
